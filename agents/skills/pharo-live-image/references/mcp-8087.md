# Genie MCP on Port 8087

Genie serves MCP over HTTP at:

```text
http://localhost:8087/mcp
```

Initialize:

```bash
curl -s -m 5 -X POST http://localhost:8087/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"smoke-test","version":"1"}}}'
```

List tools:

```bash
curl -s -m 5 -X POST http://localhost:8087/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}'
```

Call a tool:

```bash
curl -s -m 5 -X POST http://localhost:8087/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"run_test","arguments":{"package_name":"MyProject-Tests"}}}'
```

The tool result content is a JSON string containing Genie response fields such
as `success`, `result`, and `error`.
